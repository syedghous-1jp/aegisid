# Security Policy

## Supported versions
Only the latest release on `main` receives security fixes.

## Reporting a vulnerability
- **Do NOT open a public issue for exploitable bypasses.**
- Email / DM the maintainer (add your contact here).
- Include a minimal proof-of-concept against `scripts/attack_simulator.py`.

## Disclosure
- 90-day coordinated disclosure.
- Reporters credited in README and release notes.

## Bug bounty (community)
A working bypass of any defense layer, with PoC, earns a permanent
"Security Researcher" credit in this repository.
